# KnopkaSbor — уведомления от кнопки сбора (курилка / обед)

Программа для Windows: висит в трее, слушает ntfy-топик и показывает окно поверх всех окон,
когда кто-то жмёт кнопку на ESP32 (1 нажатие — курилка, 2 — обед).

Трей: статус связи, «Позвать на курилку/обед», проверка уведомления, автозапуск с Windows,
настройки, версия, «Проверить обновления», выход.

## Настройки — config.json рядом с exe
Пример — `config.example.json`. Топик в репозиторий не кладётся: он в `topic.txt`
(в .gitignore) и вшивается в exe при сборке.

## Свои активности
В `config.json` есть список `activities` — каждая строка становится пунктом в трее
«позвать на …», и уведомление приходит всем, кто подписан на тот же топик.

    { "menu": "☕ Позвать на кофе", "title": "Кофе", "message": "☕ Кто за кофе?", "priority": 3 }

- menu — текст пункта в трее (если не указан — «Позвать: <title>»)
- title — заголовок уведомления
- message — текст уведомления
- priority — 1–5, по умолчанию 4 (влияет на звук в приложении ntfy на телефоне)

Если ключа `activities` нет — используются курилка и обед. После правки:
трей → «Перезапустить (применить настройки)».

## Выпуск версии
Windows:  `.\release.ps1 1.1.0`
macOS/Linux:  `./release.sh 1.1.0`

Нужны Go 1.21+ и GitHub CLI (`gh auth login`). Номер версии каждый раз больше прошлого.
