# Office Meetings

Сбор коллег на курилку, обед и что угодно ещё — по кнопке на столе или из трея Windows.

Жмёшь большую кнопку (или пункт в трее) — у всех на компах выскакивает окно в стиле
«ready check» из Доты: таймер, кнопки **✓ Принять** / **✗ Отклонить** и живой список,
кто уже принял, а кто отказался.

```
[кнопка ESP32] ──┐
                 ├──►  ntfy (интернет)  ──►  Office Meetings на каждом компе
[трей Windows] ──┘         ▲                         │
                           └──── ответы ✓ / ✗ ◄──────┘
```

Компам и кнопке не нужно быть в одной сети: всё ходит через [ntfy](https://ntfy.sh).
Подходит для офисов, где ноуты сидят в закрытой корпоративной Wi-Fi.

---

## Возможности

- Окно сбора поверх всех окон: заголовок, текст, таймер, «Принять» / «Отклонить».
- Живой список по группам: ✓ приняли, ⏳ молчат (сбор получили, но не ответили),
  ✗ отказались. После таймера молчавшие становятся «не ответили».
- В окне видно, кто позвал. Кто позвал из трея — сразу числится принявшим.
- Отказ с причиной: свой текст или быстрые варианты, причина видна всем под именем.
- Окно закрывается само через 5 с после конца таймера или когда все ответили.
- Свои активности в `config.json`: курилка, обед, кофе, созвон — что угодно.
- Позвать коллег можно прямо из трея, без кнопки.
- Статус связи в трее: цветной значок — на связи, серый — переподключается.
- Автозапуск с Windows — галочкой в трее.
- Обновление в один клик из GitHub Releases, с проверкой контрольной суммы.
- Один exe, без установки, без прав администратора.

## Установка (для коллег)

1. Скачай `OfficeMeetings.exe` из последнего релиза.
2. Положи в постоянную папку, например `C:\OfficeMeetings\`.
3. Запусти. SmartScreen может предупредить о неизвестной программе
   (exe без цифровой подписи) → «Подробнее» → «Выполнить в любом случае».
4. Значок появится в трее. Правый клик → «Запускать вместе с Windows».
5. Правый клик → «Открыть настройки» → впиши своё имя в `name`
   → «Перезапустить (применить настройки)».

Чтобы проверить, как выглядит окно: трей → «Проверить окно сбора»
(в сеть ничего не уходит).

## Настройки — `config.json`

Лежит рядом с exe, создаётся при первом запуске. Пример — `config.example.json`.

```json
{
  "name": "Серёга",
  "server": "https://ntfy.sh",
  "topic": "",
  "token": "",
  "proxy": "",
  "update_repo": "SerejaCrystalys/office_meetings",
  "ready_timeout": 60,
  "activities": [
    { "menu": "🚬 Позвать на курилку", "title": "Курилка", "message": "🚬 Сбор на курилку!" },
    { "menu": "🍲 Позвать на обед",    "title": "Обед",    "message": "🍲 Сбор на обед!" },
    { "menu": "☕ Позвать на кофе",     "title": "Кофе",    "message": "☕ Кто за кофе?", "priority": 3 }
  ]
}
```

| Поле | Описание | По умолчанию |
|---|---|---|
| `name` | имя в списке ответивших | имя пользователя Windows |
| `server` | адрес ntfy-сервера | `https://ntfy.sh` |
| `topic` | топик сборов; пусто — берётся вшитый в exe | вшитый при сборке |
| `token` | токен доступа, если свой ntfy с авторизацией | — |
| `proxy` | прокси, если в интернет только через него (`http://host:port`) | — |
| `update_repo` | репозиторий с релизами | `SerejaCrystalys/office_meetings` |
| `ready_timeout` | секунд на ответ «Принять / Отклонить» | `60` |
| `activities` | пункты «Позвать на …» в трее | курилка и обед |
| `decline_reasons` | быстрые варианты причины отказа (до 8); `[]` — без них | «Занят», «На созвоне»… |

### Активности

| Поле | Описание |
|---|---|
| `menu` | текст пункта в трее; если пусто — «Позвать: <title>» |
| `title` | заголовок окна сбора |
| `message` | текст под заголовком |
| `priority` | 1–5, по умолчанию 4 — влияет только на звук в приложении ntfy на телефоне |

Если ключа `activities` нет — используются курилка и обед.
После правки: трей → «Перезапустить (применить настройки)».

## Кнопка на ESP32

Прошивка — в `firmware/office_meetings_button/`.

**Железо:** ESP32-C3 SuperMini, большая кнопка без фиксации, светодиод 5 мм,
резистор 220–330 Ом, питание по USB-C.

| Пин | Куда |
|---|---|
| GPIO3 | кнопка → GND |
| GPIO4 | резистор → (+) светодиод (−) → GND |

**Нажатия:** 1 — курилка, 2 быстрых — обед.

**Светодиод:**

| Что видно | Что значит |
|---|---|
| быстро мигает | подключается к Wi-Fi / Wi-Fi пропал |
| тускло горит | на связи, готова |
| ярко мигает 1 или 2 раза | сбор отправлен |
| частая дробь | не отправлено: кулдаун, нет сети, ошибка сервера |

**Прошивка:**
1. Скопируй `secrets.example.h` в `secrets.h` и заполни Wi-Fi и топик (из `topic.txt`).
   Wi-Fi нужен обычный, 2.4 ГГц, с интернетом — без страницы входа и без WPA2-Enterprise.
2. Arduino IDE + пакет **esp32 by Espressif Systems**.
3. Tools: Board **ESP32C3 Dev Module**, **USB CDC On Boot: Enabled**, нужный порт.
4. Upload. Serial Monitor на 115200 покажет подключение и отправку.

## Как ходят сообщения

- **Сбор** — в основной топик: `title` и `message`, как обычное ntfy-уведомление.
  Его же видят телефоны, подписанные на топик в приложении ntfy.
  Сбор из трея несёт тег `from:<имя>` — так видно, кто позвал (у кнопки тега нет).
- **Ответ** — в топик `<топик>-r`, телом JSON:
  ```json
  {"call": "<id сбора в ntfy>", "client": "<id копии программы>", "name": "Серёга", "answer": "decline", "reason": "На созвоне"}
  ```
  `answer` — `accept` или `decline`, `reason` — необязательная причина отказа (до 80 символов).
  Ещё программа сама шлёт `seen`, как только сбор до неё дошёл, — так в окне видно,
  кто получил сбор, но молчит. Тот, кто позвал из трея, сразу шлёт `accept`.
  При обрыве связи ответ повторяется ещё 2 раза. Телефоны ответов не видят.
- Сообщения старше 2 минут после переподключения не показываются,
  чтобы утром не прилетели вчерашние сборы.

## Сборка и релиз

Нужны Go 1.21+ и GitHub CLI (`gh auth login`).

Топик в репозиторий не кладётся: он хранится в `topic.txt` (в `.gitignore`)
и вшивается в exe при сборке.

Выпустить версию:

```powershell
# Windows
powershell -ExecutionPolicy Bypass -File .\release.ps1 1.3.1
```
```bash
# macOS / Linux
./release.sh 1.3.1
```

Скрипт соберёт `OfficeMeetings.exe` с этим номером и создаст релиз `v1.3.1`
с единственным файлом `OfficeMeetings.exe`.
Номер версии каждый раз должен быть больше прошлого.
Версии до 1.3.0 (`KnopkaSbor.exe`) сами не обновятся — их нужно один раз
заменить вручную, скачав `OfficeMeetings.exe` из релиза.

Ручная сборка:

```bash
GOOS=windows GOARCH=amd64 CGO_ENABLED=0 go build -trimpath \
  -ldflags "-s -w -H windowsgui -X main.version=1.3.1 -X main.defaultTopic=$(cat topic.txt)" \
  -o OfficeMeetings.exe .
```

## Безопасность

- Топик — это пароль: кто его знает, тот видит сборы и может их слать.
  Не публикуй его; держи только в `topic.txt`, `config.json` и `secrets.h`.
- Репозиторий публичный: обновления ставятся с него. Включи двухфакторную
  авторизацию на GitHub — кто зайдёт в аккаунт, тот сможет выкатить свой exe.
- Для полного контроля можно поднять свой ntfy с авторизацией и указать
  `server` и `token`.

## Если что-то не так

| Симптом | Что проверить |
|---|---|
| Значок серый | нет интернета или нужен прокси → `proxy` в `config.json` |
| Окно сбора не приходит | одинаковый ли топик в программе и в `secrets.h` кнопки |
| Вместо красивого окна — простое | на компе нет WebView2 Runtime, поставь его от Microsoft |
| «Проверить обновления» — HTTP 403 | лимит GitHub (60 запросов в час на IP), повтори позже |
| Кнопка быстро мигает | не подключилась к Wi-Fi: имя/пароль, 2.4 ГГц, не Enterprise |
| Serial Monitor молчит | `USB CDC On Boot: Enabled` и перезалить |
